# CASM
A poorly written assembler of course!

![CASM title image](./graphics/title/title.png)

I initially developed it for my 48xxCP CPU (48xxCony Processor) in the mist of understanding how CPUs worked. Developed in C and Python for better flexibility.

> Python version is found in the Python folder, but after realizing that this version was a lot heavier than C, I decided to put the python version into a halt till further notice. But for some who would like the Python  version, don't worry. It will be back.
>Also, the 48xxCP is also under development, so don't be surprised if you do not see the repo yet
